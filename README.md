# Agile Fintech Product Delivery Simulation

**Simulated agile delivery case study | Fintech budgeting application | Six sprints**

This repository presents an agile product-delivery simulation for a fictional fintech budgeting application delivered by a cross-functional team over six sprints.

## Business problem

Customers need a simple, reliable budgeting application that helps them plan spending, categorize transactions, monitor progress against budgets and receive timely insights. The delivery team must balance customer value, regulatory requirements, technical quality and release timing.

## Simulated role

Scrum Master / Agile Project Coordinator responsible for backlog facilitation, sprint planning, impediment removal, stakeholder communication, agile metrics and release readiness.

## Methodology

Scrum, with product backlog management, sprint planning, daily coordination, sprint reviews, retrospectives and incremental release planning.

## Planned artifacts

- Product vision
- Product roadmap
- Prioritized product backlog
- User stories and acceptance criteria
- Six sprint plans
- Sprint review notes
- Velocity and burndown charts
- Impediment log
- Retrospective action register
- Release-readiness report

## Decision-making simulation

An urgent regulatory requirement is introduced mid-delivery. The case study will evaluate its impact on scope, schedule, quality and stakeholder expectations, then document a transparent trade-off decision and revised sprint plan.
